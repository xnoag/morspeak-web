# 내부 사용 현황 보고서

`/tracking/internal`은 기존 공유 보고서와 분리된 36명 구성 자료다. 운영DB를 읽거나 쓰지 않으며 실제 측정 실적을 나타내지 않는다. 모든 이름은 가명이며 발화 원문 대신 카테고리만 전달한다. 기존 SK행복나눔 공유 페이지는 유지한다.

기존4개 구성본의 날짜별 행을 독립적으로 배분해 사용일·일별사용량·오타·기능/시간 통계를 다시 계산한다. 36개 고유 이름/ID/시작일/하루 켜둔시간 설정을 갖고, 주기적인 짧은날과 드문 하루 미사용을 유지한다. 초기자료는2026-11-10까지, 이후는 독립적인 서버시간표다. 실제 기기 수신은 아니다.

36명 전체의 목록 요약과 선택한1명의 상세만 전송한다. 다른 사람 선택 시 같은 URL의 해시를 보존해 상세를 불러온다. 비밀번호·쿠키·캐시는 기존 페이지와 분리한다. 브라우저에는 scrypt 해시와 HMAC 키를 전달하지 않는다. `TRACKING_INTERNAL_PASSWORD_HASH`와 `TRACKING_INTERNAL_SESSION_SECRET`은 환경변수로만 보관한다. 보고서·개별파일·피드 모두 인증 필요, seed와manifest원본 경로는 제공하지 않는다.

상단은 최신 검정 모스픽 로고만 표시한다. 곧장기부 로고와 구분선을 제거한다. 기존 가온 레이아웃·개요/기능/발화범주/일별/세션·다운로드UI없음은 유지한다.

생성 `node scripts/build-internal-report.mjs`, 검증 `node scripts/check-internal-report.mjs`. 생성 시 기존공유파일/운영DB는 수정하지 않는다.
