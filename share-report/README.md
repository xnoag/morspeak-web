# SK행복나눔 공유 보고서

주소: `/share/skhappiness`. 운영 앱·Firestore와 연결하지 않은 구성 자료다. 네 명의 가명 프로필과 기준 사용량을 별도 서버 시간표로 누적한다. 실제 사용자 실적·수신 증거로 사용하지 않는다.

- 브라우저 전달 데이터는 표현 카테고리·분류·오류의 수치뿐이다. 발화 원문·의도문·수정 전 입력·단축어 내용은 데이터와 API에 포함하지 않는다.
- 이름에는 `(가명)`을 표기한다. 디자인은 기존 공유 보고서의 가온 스타일, 대표가 마지막으로 제공한 검정 모스픽 PNG를 원본 그대로 사용하며 /Tracking 문구를 표시하지 않는다.
- 사용한 날의 기능 빈 항목은 구성 자료의 이벤트로 보완했다. 원본 자료는 별도 저장소에 보존하며 이 사이트는 문장을 저장하지 않는다.
- `data.json.gz`와 나머지 자산은 Next route handler를 통해 인증 후에만 전달한다. `usage-seed.json`과 README는 라우트에서 제공하지 않는다. 서버 함수 추적에만 포함한다.
- `SKHAPPINESS_PASSWORD_HASH`: scrypt 해시. `SKHAPPINESS_SESSION_SECRET`: 서버 HMAC 키. 원문 비밀번호·인증값은 소스에 저장하지 않는다. 미설정 시 503으로 차단한다.
- 로그인은 HttpOnly/Secure/SameSite=Lax 쿠키, 전용 경로, 1년 수명이다. 인증 접속마다 갱신하며 다른 브라우저·쿠키 삭제 후에는 재로그인한다.
- `/usage`는 서버 현재 시각까지의 고정 난수 시간표를 페이지로 반환한다. 창이 닫혀도 다음 요청 때 같은 시간표를 계산한다. 백그라운드 DB 수신·실기기 연결·영구 로그 쓰기는 아니다. 브라우저는 15초마다 갱신하고 커서로 중복을 배제한다.
- 기준 버전 `v12-categories`, 시간표 `shared-usage-v3`, 시작 2026-11-06 KST. 서버·클라이언트 날짜를 혼동하지 않는다.

검증: `node scripts/check-skhappiness-share.mjs`, `npm run build`. HTTP 로그인/쿠키/데이터 차단과 PC·모바일 화면은 배포 주소에서 별도 검증한다.

## v12 변경

- 발화 기록은 시간·표현/요청/응답 범주·소리내어 말하기/문자 발신 구분만 표시한다. 문장 원문은 계속 제외한다. CSV 및 전체 JSON 다운로드 UI를 제거했다.
- 하루 평균 발화 = (소리내어 말하기 횟수 + 문자 발신 수) / 앱 사용일. 받은 문자와 보호자 호출은 제외한다. 일상표현/오류 통계는 소리내어 말하기 기준임을 표시한다.
- 세션 기록은 날짜별 24시간 막대·총사용시간·세션 수의 시간표다. 휴무일도 빈 막대로 보여 주며 연속 미사용일은 최대1일이다. 구성 자료의 패턴은 SYN001수요일, SYN002일요일, SYN003격주수요일, SYN004화요일이다. 원본 기록은 Git/이전 저장소에서 보존한다. 패턴에 맞추어 구성본의 날짜를 옮기고 부족한 날짜를 같은 카테고리 수치로 보완했다.
- 정영수만 2026-05-17부터 구성한다. 다른3명은 2026-08-01 시작을 유지하고 인물별 기간을 표시한다.
- `scripts/update-share-activity.mjs`와 `scripts/extend-youngsu-history.mjs`는 이전 기준본에 대한 일회성 구성 마이그레이션이다. 이미 적용된 현재 자료에 재실행하면 차단한다.

## v13 시간과 건수 기준

- 켜둔 시간과 활성 시간을 별도 집계한다. 활성은 발화·발신·호출·IoT·영상 선택·앱 조작의 각 시점 전후420초를 합집합으로 계산하며, 수신 문자/세션 시계/수동으로 켜둔 구간은 활성 입력으로 세지 않는다. 현재 시각 뒤의 구간은 세지 않는다.
- 구성본의 켜둔 시간 목표는 사용일 평균12~13시간, 활성은5~6시간이다. 실제 측정값이 아니다. 기존 발화/발신 행은 바꾸지 않고 별도의 내용 없는 앱 조작 이벤트로 시간 구성을 보완했다. 해당 이벤트는 발화 행·건수에 포함하지 않는다. 원본 기록은 이전 커밋에 보존한다.
- 개요 평균 및 일별 시간표에 두 수치를 함께 표시하고, 시간표는 옅은 켜둔 구간 위에 진한 활성 구간을 겹친다. 합산 기준을 보수적 사용 시간으로 설명한다.
- 발화 누적·평균·날짜별·발화 기록은 같은 말하기 행+문자 발신 행으로 집계한다. 필터에서는 현재 조건과 전체 건수를 구분한다.
- 모스픽 로고는 두 번째 첨부 원본, 함께 표시하는 로고는 곧장기부 첨부 원본이다. 파일 변형 없이 CSS 표시 영역으로 투명 여백·높이·간격을 맞춘다. /Tracking과 다운로드 UI는 표시하지 않는다.
- 버전 `v13-activity`, 공통 시간표 `shared-usage-v4`이다. 기존 발화 시간표의 난수 기준은 shared-usage-v3으로 고정해 시간 지표 보완으로 기존 발화가 바뀌지 않게 했다.

시각 보완: 상단 두 로고는 약10~15% 줄이고 곧장기부만1.5px 위로 맞췄다. 타임라인은 켜둔 배경/7분 합집합의 가는 띠/개별 동작의 짧은 마커를 구분한다. 마커는 시점을 나타내며 폭을 활성 시간으로 합산하지 않는다. 따라서 자세한 동작을 보이기 위해 기존 기록이나 시간 합계를 바꾸지 않는다.

## v14 켜둔 구간 연결

켜둔 구간 사이의 큰 공백은 하루 최대2개(2~3개의 켜둔 구간)가 되도록 가까운 구간부터 연결한 뒤 기존12~13시간 목표에 맞춰 여백을 재분배한다. 원문 없는 발화/문자/앱조작 행과 활성 합계는 그대로 보존한다. 과거155일의 켜둔 구간만 바뀌었다. 현재 버전은 v14-availability/shared-usage-v5이며, 모든 과거 날짜와 향후90일의 중간 공백 최대2개를 검증한다. 모스픽은 마지막 검정 첨부 PNG로 교체하고 기존 크기/곧장기부 정렬은 유지했다.

## v15 드문 미사용과 짧은 사용일

주간/격주 패턴은 유지하되 네 번째 짧은 사용일만 완전 휴무로 둔다. 이전 완전미사용60일 중47일을 짧은 사용일로 구성해 미사용은 프로필 순서3/3/1/6일로 줄였다. 짧은 날은 켜둔4~5시간대/활성2~3시간대로 구성하고 원문 없는 발화·발신·호출·시청·IoT 행도 함께 추가해 건수를 맞춘다. 전체 사용일 평균은 켜둔12~13h/활성5~6h를 유지하므로 일반 사용일의 켜둔 시간은 평균보다 길 수 있다. 기존 모든 발화/문자 행을 ID별로 보존하고 이전0행 날짜에만 추가했다. 현재 v15-short-days/shared-usage-v6. 버전이 달라지면 같은 주소를 자동 새로고침해 재시도 상태로 머물지 않는다.
