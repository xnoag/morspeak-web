# SK행복나눔 공유 보고서

주소: `/share/skhappiness`. 운영 앱·Firestore와 연결하지 않은 구성 자료다. 네 명의 가명 프로필과 기준 사용량을 별도 서버 시간표로 누적한다. 실제 사용자 실적·수신 증거로 사용하지 않는다.

- 브라우저 전달 데이터는 표현 카테고리·분류·오류의 수치뿐이다. 발화 원문·의도문·수정 전 입력·단축어 내용은 데이터와 API에 포함하지 않는다.
- 이름에는 `(가명)`을 표기한다. 디자인은 기존 공유 보고서의 가온 스타일, 모스픽 공식 내비게이션 로고를 사용한다.
- 사용한 날의 기능 빈 항목은 구성 자료의 이벤트로 보완했다. 원본 자료는 별도 저장소에 보존하며 이 사이트는 문장을 저장하지 않는다.
- `data.json.gz`와 나머지 자산은 Next route handler를 통해 인증 후에만 전달한다. `usage-seed.json`과 README는 라우트에서 제공하지 않는다. 서버 함수 추적에만 포함한다.
- `SKHAPPINESS_PASSWORD_HASH`: scrypt 해시. `SKHAPPINESS_SESSION_SECRET`: 서버 HMAC 키. 원문 비밀번호·인증값은 소스에 저장하지 않는다. 미설정 시 503으로 차단한다.
- 로그인은 HttpOnly/Secure/SameSite=Lax 쿠키, 전용 경로, 1년 수명이다. 인증 접속마다 갱신하며 다른 브라우저·쿠키 삭제 후에는 재로그인한다.
- `/usage`는 서버 현재 시각까지의 고정 난수 시간표를 페이지로 반환한다. 창이 닫혀도 다음 요청 때 같은 시간표를 계산한다. 백그라운드 DB 수신·실기기 연결·영구 로그 쓰기는 아니다. 브라우저는 15초마다 갱신하고 커서로 중복을 배제한다.
- 기준 버전 `v11-summary`, 시간표 `shared-usage-v2`, 시작 2026-11-06 KST. 서버·클라이언트 날짜를 혼동하지 않는다.

검증: `node scripts/check-skhappiness-share.mjs`, `npm run build`. HTTP 로그인/쿠키/데이터 차단과 PC·모바일 화면은 배포 주소에서 별도 검증한다.
